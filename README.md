# Spotify_Analyzer

## Problem Statement
Spotify is a music streaming app with methods to recommend music. These recommendations however are not the best at finding music that is new or uncommon. Our project aims to allow users to use Spotify integration to curate their own music discovery. This project should allow a user to connect their account, choose target playlists, artists or songs, and generate a playlists of recommendations; A way for users to find and  playlist creator based on similar music (“cadences” Spotify Open API)
## Target Users

Spotify users dissatisfied with current playlist recommendation algorithms
People looking for new music software & comparing differing pros/cons
